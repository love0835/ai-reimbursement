AI 報賬抓信

個人自用的 Gmail 唯讀小程式，只在開發者自己的 Windows 電腦上執行。
A personal, read-only Gmail helper that runs only on the developer's own Windows computer.

它做什麼

  • 每天從開發者自己的 Gmail 找出白名單寄件者寄來的 invoice 和信用卡電子帳單（目前是 AI 服務供應商與發卡銀行），把 PDF 存到同一台電腦的資料夾，供每月報帳使用。
  • 白名單寫死在本機設定檔裡，程式只搜尋這些寄件者的信，不會搜尋或讀取其他信件。
  • 寄件網域或 Gmail 寄件驗證（DKIM／SPF／DMARC）對不上的信，一律不下載，用來擋假冒的釣魚信。
  • 權限只申請 gmail.readonly（唯讀）：不能寄信、不能刪信、不能改任何設定。

What it does

  • Once a day, it looks in the developer's own Gmail for invoices and credit-card e-statements from an allowlist of senders (currently AI service providers and the card-issuing bank), and saves the PDFs to a folder on the same computer for monthly expense reports.
  • The allowlist is a local configuration file. The program searches only for mail from those senders and does not search or read any other mail.
  • Messages whose sender domain or Gmail authentication results (DKIM / SPF / DMARC) do not match are never downloaded.
  • It requests only the gmail.readonly scope: it cannot send, delete or modify anything.

誰可以用 / Who can use it

只有開發者本人。這不是公開服務，不開放其他人登入，也沒有伺服器。
Only the developer. It is not a public service, other people cannot sign in, and there is no server.

資料只存在開發者自己的電腦上，不上傳、不分享給任何人。詳見隱私權政策 / Privacy Policy。
