隱私權政策 / Privacy Policy

適用於「AI 報賬抓信」（以下稱本程式）。生效日期 / Effective: 2026-10-21

1. 適用範圍 / Scope

本程式是開發者個人自用的工具，只在開發者自己的 Windows 電腦上執行，只存取開發者本人的 Gmail 帳號。本程式沒有伺服器，也不提供給其他人使用。

This program is a personal tool. It runs only on the developer's own Windows computer and accesses only the developer's own Gmail account. It has no server and is not offered to anyone else.

2. 讀取哪些 Google 使用者資料 / Data accessed

  • 權限只有 https://www.googleapis.com/auth/gmail.readonly（唯讀）。本程式不寄信、不刪信、不改標籤或設定。
  • 只搜尋本機設定檔裡白名單寄件者的信：AI 服務供應商的 invoice，以及發卡銀行寄來的信用卡電子帳單。搜尋條件由程式依白名單產生，不接受其他搜尋字串。
  • 對白名單寄件者的信，本程式讀取：寄件者、主旨、日期、Gmail 寄件驗證結果（DKIM／SPF／DMARC），以及信件內容，用途只有找出 PDF 附件或信中 Stripe 官方網域的 invoice PDF 下載連結。
  • 設定白名單時，開發者可以手動執行一次「探查」模式：在自己電腦的畫面上列出近 120 天像帳單的信的寄件者與主旨，用來確認寄件地址。這個結果只顯示在畫面上，不存檔。

The only scope is gmail.readonly. The program searches only for messages from an allowlist of senders (AI service providers' invoices and the card-issuing bank's e-statements). For those messages it reads the sender, subject, date, authentication results and message content, solely to find PDF attachments or the invoice PDF link on Stripe's official domain. An optional, manually run "discover" mode shows the sender and subject of invoice-like messages from the last 120 days on the developer's own screen, without saving them.

3. 怎麼使用 / How data is used

只用來把白名單寄件者的 invoice 和帳單 PDF 存到開發者自己的電腦，作為開發者每月報帳的原始憑證。不用於廣告、不出售、不做使用者分析、不用來訓練任何 AI 模型。

Data is used only to save allowlisted invoices and statements as PDFs on the developer's own computer, as source documents for the developer's monthly expense reports. It is not used for advertising, not sold, not used for profiling, and not used to train any AI model.

4. 存在哪裡 / Where data is stored

  • 只存在開發者自己的電腦上。下載的 PDF 存在本機的報帳資料夾。
  • Google 授權（refresh token）存在 Windows 認證管理員，只有開發者的 Windows 帳號讀得到。
  • 執行紀錄只記信件 ID、日期、寄件網域、存檔檔名、發票號與檔案雜湊值，不記信件內文、下載連結或授權碼。
  • 信件內文不存檔。

Everything stays on the developer's own computer. PDFs are saved to a local folder. The Google refresh token is kept in Windows Credential Manager. Logs contain only message IDs, dates, sender domains, file names, invoice numbers and file hashes; they never contain message bodies, download links or tokens. Message bodies are not saved.

5. 分享與傳輸 / Sharing

  • 本程式不把任何 Gmail 資料傳給第三方。它只連線到 Google 的 Gmail API，以及在信中只有連結時，連到 Stripe 官方網域下載該張 invoice PDF。
  • 存下的 PDF 之後由開發者自己在本機開啟、整理成報帳文件交給所屬公司。開發者整理時會使用自己的 AI 助理工具（Claude Code）讀取這些 PDF，該工具依其服務條款處理內容。

The program does not send any Gmail data to third parties. It connects only to Google's Gmail API and, when a message contains only a link, to Stripe's official domain to download that invoice PDF. The developer later opens the saved PDFs locally to prepare expense reports for their employer, using their own AI assistant tool (Claude Code), which processes the content under its own terms.

6. 保存期間與刪除 / Retention and deletion

PDF 依報帳需要保存在本機；刪除本機資料夾即完全刪除。撤銷授權的方式：到 Google 帳戶 > 第三方存取權 移除本程式，或在本機執行本程式的撤銷指令（同時刪除本機儲存的授權）。

PDFs are kept locally as long as needed for expense records; deleting the local folder removes them completely. To revoke access, remove this app at Google Account > Third-party access, or run the program's local revoke command, which also deletes the stored token.

7. 政策變更 / Changes

如果本程式讀取的資料或用途改變，會先更新本頁並修改生效日期。

If the data accessed or its use changes, this page and its effective date will be updated first.
